# START HERE — Universal Prompt System v1.0

1. Load the system layer.
2. The Router determines `Mode + Language + Prompt Version`.
3. Verify `Requested Mode = Loaded Mode` and the exact file metadata.
4. Load one canonical Mode file and its declared namespace.
5. Old context does not become new project State automatically.
6. Start Lock blocks Project ID and active State until explicit Start confirmation.
7. Resume restores the same Project ID and pinned tuple from a valid Export.
8. Any conflict, damaged Export, or ambiguous source opens Recovery.
9. Project Export is the same project; Project Copy is a new project.
10. Final requires separate explicit confirmation; Reopen preserves history and Project ID.

Read `CORE-SYSTEM-HARDENING-v1.0.md`, `MAIN-ROUTER-v1.0.md`, and `MODES.md` before using a Mode.
