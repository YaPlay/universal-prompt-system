# Contributing

Thank you for helping improve Universal Prompt System.

## Scope

Changes should preserve the Core contracts, exact Mode × Language registry, numbering, command identity, and the distinction between Project Export and Project Copy. Do not add a new Mode, language, or version without updating the system registry and documentation.

## Before proposing a change

- read `system/START-HERE.md`, the Core Hardening file, Router, and registry;
- keep changes limited to the requested scope;
- preserve Markdown structure, code fences, metadata, and localized semantics;
- do not include `.DS_Store`, secrets, environment files, logs, or editor caches;
- run structural, registry, link, and cross-language checks appropriate to the change.

## Pull requests

Describe the files changed, the behavior affected, the checks performed, and any known limitations. Prompt changes should include the relevant Mode and language parity impact. Do not claim a release or final status without evidence from the real files.
