# Universal Prompt System — Español

Universal Prompt System es un marco declarativo de prompts Markdown para el trabajo estructurado en proyectos. Una capa Core separada de los siete Modos utiliza la tupla exacta `Mode + Language + Prompt Version`.

## Versión

Versión actual: `v1.0`. Hay siete Modos disponibles en cinco idiomas: RU, EN, FR, ES y UA.

Modos: Standard, RPG, Sakura, Cyber, Anime Magic, Executive y Study.

Empieza con [`system/START-HERE.md`](../system/START-HERE.md), después lee el Router y el registro antes de cargar un Modo. Solo se pueden seleccionar archivos registrados exactamente; los datos ausentes o conflictivos pasan a `Fallback` o `Recovery`.

El sistema es una especificación prompt-based/declarative. No es un Router ejecutable ni un servicio de persistencia.

Consulta el [README raíz](../README.md) para el mapa del repositorio y la documentación localizada.
