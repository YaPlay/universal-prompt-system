# Universal Prompt System — Français

Universal Prompt System est un cadre déclaratif de prompts Markdown pour le travail structuré sur des projets. Une couche Core séparée des sept Modes utilise le tuple exact `Mode + Language + Prompt Version`.

## Version

Version actuelle : `v1.0`. Sept Modes sont disponibles en cinq langues : RU, EN, FR, ES et UA.

Modes : Standard, RPG, Sakura, Cyber, Anime Magic, Executive et Study.

Commencez par [`system/START-HERE.md`](../system/START-HERE.md), puis lisez le Router et le registre avant de charger un Mode. Seuls les fichiers enregistrés exactement peuvent être sélectionnés ; les données absentes ou conflictuelles ouvrent `Fallback` ou `Recovery`.

Le système est une spécification prompt-based/declarative. Ce n'est ni un Router exécutable ni un service de persistance.

Consultez le [README racine](../README.md) pour la structure du dépôt et les documents localisés.
