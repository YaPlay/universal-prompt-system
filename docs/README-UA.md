# Universal Prompt System — Українська

Universal Prompt System — декларативна Markdown-система промптів для структурованої роботи над проєктами. Окремий Core-рівень і сім ізольованих режимів використовують точний tuple `Mode + Language + Prompt Version`.

## Реліз

Поточний реліз: `v1.0`. Сім режимів доступні п'ятьма мовами: RU, EN, FR, ES та UA.

Режими: Standard, RPG, Sakura, Cyber, Anime Magic, Executive і Study.

Почніть із [`system/START-HERE.md`](../system/START-HERE.md), потім прочитайте Router і реєстр перед завантаженням режиму. Вибираються лише точно зареєстровані файли; відсутні або конфліктні дані спрямовуються до `Fallback` чи `Recovery`.

Система є prompt-based/declarative специфікацією. Це не виконуваний Router і не сервіс збереження стану.

Дивіться [кореневий README](../README.md), щоб переглянути структуру репозиторію та локалізовану документацію.
